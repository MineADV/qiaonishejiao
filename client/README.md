# 悄匿社交 · 客户端

一个**自研可靠 UDP 传输**的聊天程序的图形客户端（customtkinter）：登录、侧栏会话、
消息渲染、文件与头像、成员列表、群管理、中国象棋、7 套主题。

> 这是**客户端仓库**。服务端源码在另一个仓库（`fwd`）。
> 两边通过自研 UDP 协议通信，共用 `chat_common.py` / `chat_net.py` 两个文件。

---

## 目录内容

| 文件 | 作用 |
| --- | --- |
| `chat_gui.py` | 图形界面主体：登录页、侧栏、消息渲染、设置、诊断日志（customtkinter） |
| `chat_client_core.py` | 客户端网络核心（无界面）：登录认证、收发、文件分块、事件队列 |
| `chat_cli.py` | 命令行客户端（调试 / 无界面环境用） |
| `chat_chess_ui.py` | 象棋棋盘窗口（PIL 绘制 + 走子交互） |
| `chat_chess.py` | 中国象棋规则（**与服务端同一份**，界面画棋盘要用） |
| `chat_sound.py` | 提示音：7 种音效内存合成，不依赖音频文件 |
| `chat_notify.py` | 右下角通知：任务栏托盘气泡 + 屏幕浮窗兜底 |
| `chat_secret.py` | 本机密码保管（Windows DPAPI 加密） |
| `chat_geo.py` | IP 属地查询（客户端自己算「我的属地」） |
| `chat_common.py` | 协议常量、报文编解码、PBKDF2 + AES-GCM（**与服务端共用**） |
| `chat_net.py` | 可靠 UDP 信道：滑动窗口 / 累积确认 / 快速重传 / 心跳（**与服务端共用**） |
| `requirements.txt` | 客户端依赖 |
| `build.ps1` | 打包成免安装 exe |
| `客户端说明.md` | 更细的使用说明（界面行为、排障） |

## 快速开始

### 直接跑源码

```bash
pip install -r requirements.txt
python chat_gui.py
```

或者用命令行客户端连一下（排查连通性最快）：

```bash
python chat_cli.py --host 192.168.1.5 --port 26000 --nick 你的昵称
```

### 登录

登录界面填四项：**服务器地址、端口、昵称、密码** → 首次点「注册」，之后点「登录」。
四个输入框里**任意一个按回车都能提交**，打开界面时会自动聚焦到还没填的那一栏。

| 项目 | 默认行为 |
| --- | --- |
| 服务器地址 / 端口 / 昵称 | **登录成功后自动记住**，下次打开自动填好 |
| 密码 | **默认不保存**，每次手输 |
| 「记住密码」开关 | 打开后：密码用 **Windows DPAPI 加密**存在本机，下次打开**自动登录** |

安全说明：保存的密码写在同目录 `client_config.json` 里，但是**密文**（`dpapi1:` 开头），
用当前 Windows 用户的凭据加密，**换机器、换 Windows 账号都解不开**；
不勾选就绝对不保存，关掉开关会**立刻删除**本机已存的密码；加密失败时宁可不存，也绝不写明文。

### 打包成 exe

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物：`dist\client\悄匿社交.exe` + 同目录 `_internal\`（**必须一起分发，不能删**）。

## 界面功能

| 模块 | 说明 |
| --- | --- |
| 会话侧栏 | 「公共大厅 / 好友 / 群组」分区分组显示，有新消息会标记 |
| 会话切换 | 每个会话各留一份**已经画好的界面**（最多 20 个），切过去只是换显示；空闲时后台把侧栏里所有会话都预热好 |
| 消息渲染 | 一个会话最多画最近 20 条，更早的给一行「（更早的 N 条没有显示，点这里显示）」；分帧绘制，界面不卡 |
| 发送即显示 | 自己发的消息先在本机显示，服务端回显按内容指纹 + 本机等待时长去重（不会变成两个气泡） |
| 文件与图片 | 按会话发送；图片内联缩略图 + 点击放大（滚轮 / ＋－ 缩放）；视频/文件点击打开 |
| 拖拽 / 粘贴 | 文件拖进窗口即发送；`Ctrl+V` 直接发送剪贴板截图 |
| 头像 | 侧栏左下角点一下即可选图，自动裁成 256×256 上传，别人按版本号按需拉取 |
| 成员列表 | 大厅 / 群聊右侧列出成员（含属地、在线圆点、群主 👑 / 管理员 ★ / 禁言 🔇）；**右键**可 @ / 加好友 / 设管理员 / 禁言 / 移出群 / 发起私聊 |
| 群管理 | 群公告（顶部横幅）、群文件、6 位群号一键复制、审批加群与拉人、禁言 / 移出成员 |
| 撤回 | 右键自己的消息 2 分钟内可撤回；群主 / 管理员可撤回普通成员的消息（不限时间） |
| 中国象棋 | 输入框左边 ♟ 约战 → 被挑战方选红黑；绝杀 / 困毙由服务端判定；可认输、求和、悔棋（需对方同意）；退出前会确认「视为认输」 |
| 提示音 / 通知 | 7 种内存合成音效；好友 / 群消息与 @ 提及会在右下角弹系统通知（正看着那个会话时只出声） |
| 断线处理 | 顶部挂红色横幅、输入区禁用，按回车会明确提示「消息没有发出去」；掉线后自动重连（2/4/8/15/25 秒，共 5 次） |

### 7 套外观主题

午夜蓝（默认）/ 森林绿 / 霓虹紫 / 深海青 / 清透白 / 暖阳橙 / 羊皮纸。

登录页底部和聊天界面右上角都能切换，**切换是全局换肤**（侧栏、气泡、按钮、输入框、弹窗一起变），
选择会记住；换肤不会丢状态（登录状态、当前会话、聊天记录、没发出去的草稿都保留）。

### 输入框命令与快捷键

输入框里以 `/` 开头：

| 命令 | 说明 |
| --- | --- |
| `/help` | 帮助 |
| `/me <动作>` | 动作消息（仅公共大厅） |
| `/users` | 刷新在线列表 |
| `/ping` | 查看网络延迟 |
| `/clear` | 清空当前会话显示 |
| `/quit` | 断开连接 |

`Enter` 发送、`Shift+Enter` 换行（行数自动增高）。
底部按钮：😊 表情面板 / 📎 发文件 / @ 提及 / ♟ 约战象棋 / 👥 成员列表开关。

## 配置文件 `client_config.json`（exe / `chat_gui.py` 同目录）

```json
{
  "host": "192.168.1.5",
  "port": "26000",
  "nick": "demo",
  "theme": "midnight",
  "calm": false,
  "debug": false,
  "save_password": true,
  "password": "dpapi1:……"
}
```

| 字段 | 含义 |
| --- | --- |
| `host` / `port` | 上次登录的服务器地址与端口 |
| `nick` | 上次登录的昵称 |
| `theme` | 外观主题：`midnight` 午夜蓝 / `forest` 森林绿 / `violet` 霓虹紫 / `ocean` 深海青 / `light` 清透白 / `sunset` 暖阳橙 / `paper` 羊皮纸 |
| `calm` | `true` = 省电模式：关掉后台预热与动画，一个会话只画最近 8 条（老机器 / 远程桌面） |
| `debug` | `true` = 额外写 `client_trace.log` 详细流水（与设环境变量 `QIAONI_DEBUG=1` 等效） |
| `save_password` / `password` | 勾选「记住密码」后写入：前者是开关，后者是 `dpapi1:` 开头的 DPAPI 密文 |

## 诊断与排障

客户端目录会有这些文件：

| 文件 | 内容 |
| --- | --- |
| `client_diag.log` | 界面诊断日志（最多 400KB 自动滚动）：构建号、窗口最小化 / 恢复、每次整块重绘及原因、每次发送结果、每 10 秒一行状态 |
| `client_error.log` | 被吞掉的异常（按钮回调出错、网络层异常等） |
| `client_trace.log` | 只有开了 `debug` 才写：每条消息的收发与历史合并流水 |

收到的文件保存在 `%TEMP%\qiaoni_recv\`，并维护索引 `index.json`（最多 400 条），
所以切会话、甚至重启客户端都能直接用本机那份，不用重新下载。

| 现象 | 先做什么 |
| --- | --- |
| 一直连不上 | 确认服务端已启动、地址/端口填对、安全组/防火墙放行 **UDP** |
| 界面卡 / 白 / 消息不显示 | 看 `client_diag.log` 最后 30 行（重绘原因 / 待画 / 遮罩 / 锁输入） |
| 客户端起不来 | 看 `client_error.log`；确认 `_internal` 完整、和 exe 同目录 |
| 消息发出去了对方没收到 | 双方是否好友 / 是否被拉黑；对方不在线时私聊会走服务端离线留言 |
| 机器很卡 / 远程桌面 | `client_config.json` 里加 `"calm": true` |

> 窗口标题统一带演示后缀「（信息学院 张伊博 项目演示用）」。
> 想改或去掉，改 `chat_gui.py` 顶部的 `APP_SUFFIX`。

## 已知限制

- **没有端到端加密**：服务端能看到消息与文件明文；注册时密码明文传输一次（历史遗留）
- `%TEMP%\qiaoni_recv\` 收到的文件**不会自动清理**（索引上限 400 条）
- 别人（成员列表 / 消息里的属地）由服务端判定，服务端不升级就还是旧结论
- 象棋、通知、DPAPI 密码保管、提示音都是 **Windows 专属**，其他系统上会退化成不可用或无声
