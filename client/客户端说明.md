# 悄匿社交 · 客户端使用说明

> 本说明对应 **2026-09-25 21:08** 打包的客户端（`悄匿社交.exe`）。
> 它要和同版本的服务端（`悄匿社交-服务端.exe`）一起换、一起用。

---

## 1. 怎么跑起来

双击 `悄匿社交.exe`。首次会看到登录页，填四样东西：

| 输入框 | 填什么 | 说明 |
| --- | --- | --- |
| 服务器地址 | 服务端的 IP 或域名 | 同一台机器自测填 `127.0.0.1`；局域网填服务端内网 IP（如 `192.168.1.20`）；公网填公网 IP / 域名 |
| 端口 | 服务端端口 | 默认 `26000` |
| 昵称 | 2–16 个字符，中文/字母/数字/下划线/短横线 | 全服唯一；没注册过会自动注册 |
| 密码 | 至少 4 位 | 登录用；服务端只保存加盐散列 |

会用源码跑：`py chat_gui.py`（需要 `PYTHONPATH` 指向本目录）。

**登录信息记忆**：登录成功后自动记住「地址 / 端口 / 昵称」；勾选「记住密码」时，
密码用 **Windows DPAPI 加密**后存进 `client_config.json`（只有当前 Windows 用户能解开），
下次打开直接自动登录。取消勾选会把保存的密码删掉。

│ ─────────────  ├──────────────────────────────────────────┤           │

## 3. 会话类型

| 类型 | 能做什么 |
| --- | --- |
| **公共大厅** | 所有在线的人都能看到；成员面板列出全部在线用户 |
| **好友私聊** | 一对一会话；侧栏会显示对方在线/离线 + IP 属地 |
| **群聊** | 群号 6 位；群主/管理员可发公告、管成员、删群文件；入群补最近 30 条历史 |
| **离线留言** | 对方不在线时消息会留在服务端（保留 30 天），对方上线后能看到 |

## 4. 发消息

| 方式 | 操作 |
| --- | --- |
| 文字 | 输入后按 **Enter** 发送；**Shift+Enter** 换行；单条最长 2000 字 |
| 表情 | 点 😊 打开面板，点一下插入（文字形式的表情） |
| 图片 / 文件 | 点 📎 选择，或**直接把文件拖进窗口**，或截图后 **Ctrl+V** 粘贴 |
| @某人 | 点 @ 选人；被 @ 的人消息会高亮，并响一次专属提示音 |
| 图片查看 | 收到的图片点一下放大预览 |

- 别人换头像时，只有那一张头像图会原地替换，消息区不会整块重画。
- **消息右键菜单**：撤回 / 复制 / 删除（撤回的可见范围见下）。

**撤回规则**：
- 自己发的消息，**2 分钟内**可以撤回；
- 群主 / 管理员撤回**群成员**的消息**不限时间**；
- 撤回后原地变成「某某撤回了一条消息」，气泡消失。

## 5. 好友与黑名单

- **加好友**：侧栏「好友」右上角 `＋ 加好友` → 搜昵称或直接发申请（可带一句留言）。
- **处理申请**：侧栏「好友申请」里点【同意】/【拒绝】（按钮是绿色/红色）。
- **删除好友**：对方头像右键（或成员列表右键）→ 删除。
- **拉黑**：同菜单 → 加入黑名单；解除也在同一处。
- **后果**：被删除或拉黑后，你们之间的输入框会被**锁住**并写明原因
  （点好友头像右键可以解除）；**大厅和群聊不受影响**，照常发言。

## 6. 群组

| 功能 | 位置 | 说明 |
| --- | --- | --- |
| 建群 | 侧栏「群组」右上角 `＋ 建群` | 自动分配 6 位群号 |
| 加群 | `＋ 加群` → 填群号 + 留言 | 群主/管理员在「加群申请」里审批 |
| 群公告 | 群聊右上角「☰ 群资料/管理」→ 发布/清除 | 群聊顶部会出现公告横幅 |
| 群文件 | 群资料窗口 → 上传 / 下载 / 删除 | 群主、管理员可删 |
| 成员管理 | 群资料窗口，或**右键成员** | 设为管理员 / 取消 / 禁言 10 分钟 / 1 小时 / 1 天 / 永久 / 解除 / 移出本群 / 发起私聊 |
| 拉好友入群 | 群资料窗口「邀请好友入群」 | **任何成员都能拉人，但必须「被拉的人」和「群主/管理员」双方都同意**才进群 |
| 被踢 / 被禁言 | 会自动弹提示 | 被禁言时输入区换成「禁言中」，到期自动恢复 |

## 7. 中国象棋

1. 输入区点 **♟** → 弹出在线名单 → 点一个人约战；
2. 对方收到约战卡片，**由被挑战方选执红（先行）还是执黑**，也可拒绝；
3. 棋盘窗口里可 **悔棋**（需对方同意）、**和棋**（需对方同意）、**认输**、**离开**；
4. 走法合法性、将军、**绝杀 / 困毙**全部由服务端判定；落子有音效；
5. 关掉棋盘可以从 ♟ 面板里「⚔ 回到当前对局」再打开；带着未下完的棋退出登录/程序会先确认（等于认输）。

## 9. 流畅性（这一版专门优化过）

| 场景 | 行为 |
| --- | --- |
| 切换聊天对象 | 每个会话各留一份**已经画好的界面**，切过去只做一次显示切换，实测 **7–70 ms**（以前要 1–2 秒） |
| 后台预热 | 空闲时把侧栏里**所有会话**提前画好；每片最多占 20 ms，而且你一动键盘/鼠标就让开 |
| 冷会话首次打开 | 新界面在**屏幕外**画好再一次性显示（20 条约 0.3 秒），期间保持原来那一块，不会出现黑块或闪 |
| 消息区重绘 | 按**时间**切帧（每帧最多 12 ms），界面全程可响应 |
| 从任务栏恢复 | 恢复时**不动任何布局**（不重排、不重画） |
| 贴底 | 切进会话一定停在最后一条；自己发的消息一定看得见；正在往上翻旧消息时不会被新消息拽回底部 |
| 图片/文件 | 收到的文件在本机留索引，切会话、重启都直接用本地那份，不再重新下载 |

## 10. 客户端文件与配置

**`client_config.json`**（exe 同目录，UTF-8）

| 字段 | 含义 |
| --- | --- |
| `host` / `port` / `nick` | 上次登录的地址、端口、昵称（自动记） |
| `save_pwd` | **DPAPI 加密**后的密码；取消「记住密码」会删掉这个字段 |
| `theme` | 上次选的主题（如 `midnight`） |
| `sound` | 提示音开关 |
| `debug` | `true` 会写详细事件流水 `client_trace.log`（排查用） |
| `calm` | `true` = **省电模式**：不后台预热、一个会话只画最近 8 条、不做动画。适合老旧机器 |
| `my_region` | 手动写死自己的属地（如 `"福建 厦门"`）。属地怎么判都不对时用这个，优先级最高 |

**「我的属地」是谁算的**：客户端自己算的那份优先（拿本机出口 IP 找 9 家库投票：
同一家库的多个域名只算一票，国内库加权，两家以上库一致才算共识），服务端下发的那份
只当兜底。这样即使服务器还是旧版本、或者它那边的库把移动出口 IP 记成别的省，
你看到的也是自己这份结论。想看服务端判成了什么，看 `client_diag.log` 里
「本地属地解析」那一行的 `服务端属地=`。

> **查不到会自动重试**：这些接口是公网的，会超时、会被挡。客户端最多重试 5 次
> （间隔 3/6/9/12/15 秒），期间先显示服务端那份（同机自测通常是「本机」）。
> 重试成功后会自动换成你自己的真实省市，不用重新登录。
> 下面那行括号里显示的是**客户端自己查到的出口 IP**（不是服务端看到的 127.0.0.1）。

**系统提示（头像已更新 / 离线留言 / 各种操作回执）**：只在右下角浮一条，
**不会写进任何聊天记录**，更不会跑到公共大厅里去。群里那些带归属的提示
（禁言、公告、被移出群…）仍然记在对应的群会话里。

**本地缓存 / 日志**

| 路径 | 内容 |
| --- | --- |
| `%TEMP%\qiaoni_recv\` | 收到的图片/文件（按 fid 固定命名）+ `index.json` 索引（最多 400 条） |
| `%TEMP%\qiaoni_paste\` | Ctrl+V 粘贴的截图临时文件 |
| `client_error.log` | 出错的堆栈（正常应为空） |
| `client_diag.log` | 界面诊断流水：窗口最小化/恢复、每次整块重绘及原因、发送结果、每 10 秒一行状态（最多 400KB 自动滚动） |
| `client_trace.log` | 更细的事件流水（仅 `debug: true` 时生成） |

## 12. 发送相关：三种提示分别是什么意思

客户端在发送这条链路上会明确告诉你卡在哪一步（不会再出现「点了没反应」）：

| 提示 | 含义 | 怎么办 |
| --- | --- | --- |
| 聊天里出现 **「⚠ 未连接服务器，这条消息没有发出去」** | 会话已掉线 | 点右上角「退出登录」重新登录 |
| 右下角 **「这条消息没有被服务器确认…」** | 消息发出去了但 5 秒内没被服务端确认（多半没送达） | 检查网络；连续出现就重新登录 |
| 聊天里 **「⚠ 发送出错：…」** | 本地异常，**你的文字还留在输入框里** | 把那行字发出来即可定位；可以直接再试一次 |
| **「输入框是空的（没读到文字）」** | 输入框状态异常或真的没输入 | 重新输入即可；若反复出现请反馈 |

另外：如果界面显示掉线、但底层链路其实是通的，客户端会在发送前**自动纠正状态**再发出去。

## 13. 常见问题

| 现象 | 处理 |
| --- | --- |
| 一直停在登录界面转圈 | 地址/端口不对，或服务端没开，或防火墙拦了 UDP；确认服务端窗口有「服务端已启动」 |
| 提示「昵称已被注册」 | 换个昵称，或直接用该昵称+正确密码登录 |
| 消息发出去但对方收不到 | 双方是否都在线；对方是否把你删了/拉黑（私聊会被服务端拒绝投递）。**图片/文件在私聊里也已经能正常送达**（旧版这里丢了，本版已修） |
| 切会话时短暂空白一下 | 新会话的内容先在屏幕外画好再一次性显示；这几百毫秒里界面会先空着，**不会再显示上一个会话的内容**（旧版会串会话） |
| 「头像已更新」这类提示找不到 | 它只在右下角浮一下、不写进聊天记录；上传完看左下角自己的头像有没有变 |
| 顶部出现「📶 网络不稳…」 | 只是十几秒收不到包，客户端会自己重试、不会断开；超过 45 秒才判离线并自动重连 |
| 界面出现黑块 / 最小化回来被重画 | 本版已处理（切会话用缓存界面、恢复不动布局）。仍有异常时把 `client_diag.log` 发出来，里面按时间记录了每次整块重绘及原因 |
| **消息区/输入框一片空白、点发送没反应、要反复点左侧会话栏才出来** | 这是「该显示的东西没挂上」。本版加了两道自救：①**显示自检**（每 2 秒）发现正文区 / 当前会话消息区 / 输入区没挂着、或高度是 0，就自己挂回去；②**渲染链兜底**：分帧渲染一旦被打断（日志里写着 `分帧渲染标记卡住（队列已空）`），自动把「画好却没显示」的那块挂上界面 —— **不用再反复点会话栏**。两者都会在 `client_diag.log` 留一行 `显示自检：…` / `兜底：…`；一切正常时一个控件都不碰 |
| 字体/表情显示成方块 | 系统缺少「微软雅黑 / Segoe UI Emoji」字体；换一台 Win10+ 或装字体 |
| 想彻底重置客户端 | 关掉程序，删掉 `client_config.json`（会忘掉主题/登录信息）与 `%TEMP%\qiaoni_recv\`（会清掉本地文件缓存） |

## 14. 这个版本包含 / 不包含

- ✅ 大厅/私聊/群聊、离线留言、文件与图片（拖拽/粘贴）、表情、@提及、撤回、好友与黑名单、群管理与群文件、拉人审批、中国象棋、7 套主题、提示音与托盘通知、登录信息记忆（含 DPAPI 加密密码）、界面流畅性优化、本地文件缓存
- ❌ **不含**游戏中心（五子棋 / 成语接龙 / 战绩排行榜）—— 那部分已在回滚中移除
- ❌ 不含端到端加密：服务端能看到消息明文（局域网/演示用途）
- ⚠️ `%TEMP%\qiaoni_recv\` 不会自动清理，长期使用可自行删除旧的接收文件

有问题请把 **`client_diag.log`** 和 **`client_error.log`** 一起发出来，里面记录了窗口状态、
每次重绘原因和每次发送的结果，可以精确定位。
