# 悄匿社交 · 服务端

一个**自研可靠 UDP 传输**的局域网 / 公网聊天程序的服务端：账号、好友、群组、
消息路由与历史、文件与头像分发、中国象棋裁判、IP 属地判定、超级管理员控制台。

> 这是**服务端仓库**。图形客户端的源码在另一个仓库（`khd`）。
> 两边通过自研 UDP 协议通信，共用 `chat_common.py` / `chat_net.py` 两个文件。

---

## 目录内容

| 文件 | 作用 |
| --- | --- |
| `chat_server.py` | 服务端主程序：认证、会话路由、消息/文件分发、象棋裁判、控制台 |
| `chat_social.py` | 账号、好友、黑名单、群组、离线留言、封禁（JSON 持久化） |
| `chat_geo.py` | IP 属地：9 个公开数据源并行查询 + 投票 + 缓存 + 人工修正 |
| `chat_chess.py` | 中国象棋规则引擎（走法 / 将军 / 绝杀 / 困毙 / 中文记谱），服务端当裁判 |
| `chat_common.py` | 协议常量、报文编解码、PBKDF2 + AES-GCM（**与客户端共用**） |
| `chat_net.py` | 可靠 UDP 信道：滑动窗口 / 累积确认 / 快速重传 / 乱序缓存 / 心跳（**与客户端共用**） |
| `requirements.txt` | 服务端依赖 |
| `build.ps1` | 打包成免安装 exe |
| `服务端说明.md` | 更细的使用说明（部署、控制台、限额、排障） |

## 快速开始

### 直接跑源码

```bash
pip install -r requirements.txt
python chat_server.py                    # 用 server_config.json 里的端口
python chat_server.py --port 27000       # 临时换端口
python chat_server.py --room 演示大厅     # 临时换大厅名
python chat_server.py --host 127.0.0.1   # 只监听本机（本机自测最安全）
```

| 参数 | 作用 | 默认 |
| --- | --- | --- |
| `--host` | 监听地址 | `0.0.0.0`（所有网卡） |
| `--port` | UDP 端口（覆盖配置文件） | 配置文件里的 `port` |
| `--room` | 公共大厅名称 | 配置文件里的 `room` |

首次运行会在**同目录**生成 `server_config.json`，然后监听 UDP **26000**，并打印局域网地址：

```
  公共大厅：公共大厅
  端    口：26000
  局域网地址（客户端请填其中任意一个）：
      192.168.1.5:26000
```

> 一个 UDP 端口只能被一个服务端占用；同一台机器开第二个必须换端口。

### 打包成 exe

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物：`dist\server\悄匿社交-服务端.exe` + 同目录 `_internal\`（**必须一起分发，不能删**）。

## 网络与部署

**局域网**：拷到任意一台机器双击即可，客户端填这台机器的内网 IP（如 `192.168.1.20`）。
Windows 防火墙第一次会弹窗，选**允许**；没弹窗就手动加一条入站规则放行 **UDP 26000**。

**公网**：两件事缺一不可 ——

1. 云服务器**安全组**放行 **UDP** 26000（注意是 UDP，不是 TCP）；
2. 路由器端口映射（家用宽带）或直接给公网 IP（云服务器）。

客户端一直连不上，就是包没到服务端：依次查 **安全组 → 防火墙 → 端口占用 → 服务端是否启动成功**。
服务端控制台敲 `geo self` 能看到自己对外解析出的地址。

一台普通家用/云主机（1 核 1G）跑几十人在线没问题；开销主要在 AES-GCM 加密和群发（一个群 N 人 = N 份报文）。

## 配置文件 `server_config.json`

```json
{
  "port": 26000,
  "room": "公共大厅",
  "geo_lookup": true,
  "public_ip": "",
  "super_admins": [],
  "geo_api": "",
  "geo_overrides": {},
  "geo_sources": ""
}
```

| 字段 | 含义 |
| --- | --- |
| `port` | 监听端口（UDP），客户端要填一样的数字 |
| `room` | 公共大厅的显示名字 |
| `geo_lookup` | 是否联网判定属地；内网 / 不想联网就设 `false` |
| `public_ip` | 手写服务端自己的公网 IP（自动探测不准时手动填） |
| `super_admins` | 超级管理员昵称列表（这些人登录后客户端会出现「🛡 控制台」） |
| `geo_api` | 自建属地接口（URL 里用 `{ip}` 占位），留空则用内置的 9 个公开源 |
| `geo_overrides` | 手工指定的 IP → 属地（一般由控制台 `geoset` + `geo save` 写入） |
| `geo_sources` | 只用指定的源，例 `"pconline,ip.sb"`；留空 = 全部 9 个 |

文件用 UTF-8 保存（带 BOM 也能读）。

## 控制台命令（在服务端窗口里直接敲）

| 命令 | 作用 |
| --- | --- |
| `help` | 打印命令表 |
| `users` / `list` | 当前在线的人 + 在线人数 / 群数 |
| `stats` | 账号数、群数、在线数、头像数、离线留言数；逐群列出成员 / 管理员 / 公告 / 群文件 / 待审批 |
| `games` | 正在进行的象棋对局 |
| `say <内容>` | 以系统身份在公共大厅广播 |
| `kick <昵称>` | 踢下线（对方可立刻重登） |
| `admin list` / `admin add <昵称>` / `admin del <昵称>` | 超级管理员名单（即时生效并写回配置） |
| `ban <昵称> [分钟\|0] [理由]` | 封号（`0` 或省略 = 永久），理由会展示给被封的人 |
| `unban <昵称>` / `bans` | 解封 / 查看封禁名单 |
| `geo <IP>` / `geo self` | 查某 IP / 本机的属地，并说明「为什么显示属地未知」 |
| `geoset <IP> <属地>` / `geo save` | 手工修正属地 / 写盘（重启也保留） |
| `files` | 文件缓存、群文件、头像、历史目录的位置与数量 |
| `quit` / `exit` | 关服（会给所有在线客户端发「服务器已关闭」） |

启动横幅里的「启动时统计」只是开机瞬间的快照，想看当前数据随时敲 `stats`。
启动后还会自动解析并打印自己的对外地址，例如 `◆ 本机对外地址：1.2.3.4（广东 广州）`。

## 账号、认证与安全

- **昵称**：2–16 个字符，支持中文 / 字母 / 数字 / 下划线 / 短横线，**全服唯一**（不区分大小写）
- **密码**：至少 4 位。服务端只保存 `PBKDF2-HMAC-SHA256(密码, 每账号独立随机盐)`，**迭代 20 万次**，不存明文
- **登录**：客户端发昵称 → 服务端回盐 + 一次性随机数 → 客户端用 `HMAC(密钥, 随机数)` 应答 → 服务端比对。
  **密码与密钥都不上网**
- **通信加密**：认证成功后，除 `HELLO` / `DENY` 外所有报文用 **AES-256-GCM** 加密；报文里带 16 字节随机会话号
- **同一账号重复登录**：新连接生效，旧连接被提示并断开

⚠️ **已知限制**：注册那一次的密码是**明文**传输的（首个报文还没协商密钥）；而且这是**链路加密，不是端到端加密** ——
服务端持有密钥，能看到消息与文件明文。面向局域网 / 内网演示，公网部署建议自行加隧道。

## 传输层（为什么 UDP 也能可靠）

| 机制 | 参数 |
| --- | --- |
| 报文头 | 固定 **34 字节**：`>4sBBBBII16sH` = 魔数 `DCHT`、版本、类型、标志、保留、序号、确认号、会话号(16)、负载长度 |
| 类型 | `K_DATA` 数据、`K_ACK` 确认、`K_PING` 心跳、`K_PONG` 心跳应答 |
| 标志位 | `F_ENC` 已加密、`F_RESET` 重建会话 |
| 发送窗口 | 128 个包；每 tick（5ms）最多发 24 个，空闲时降到 20 次/秒省 CPU |
| 确认 | 累积确认 + **连续 3 个重复确认即快速重传** |
| 超时重传 | `RTO = srtt + 4×rttvar`，范围 0.2–4 秒，每包独立指数退避 |
| 尾包补发 | 在途包很少时按 `max(0.4s, 2×srtt)` 主动补发（最后一个包丢了没人触发重传） |
| 永不放弃 | 单个包**不会**因为重传次数多而被丢弃 |
| 乱序 | 接收端缓存 320 个包，按序号重组 |
| 不分片 | 单个业务报文控制在 MTU 内；文件按 1000 字节分块流式发送 |

**保活与判死（两档，两端一致）**：

| 情况 | 行为 |
| --- | --- |
| 连续 **8 秒** 收不到任何报文 | 客户端顶部提示「网络不稳，正在自动重试」，**不断开**、不锁输入框 |
| 连续 **45 秒** 收不到 | 判离线；客户端自动重连（2/4/8/15/25 秒，共 5 次） |
| 窗口 **120 秒** 毫无确认进展 | 同样判离线（真断了不会永远挂着） |

地址漂移（云服务器多网卡、NAT 重绑）时两端会自动跟随新地址继续通信，安全性由会话号 + AES-GCM 认证保证，与源地址无关。

## IP 属地是怎么判的

- **只看 UDP 报文的来源地址**，完全不采信客户端上报的信息，所以客户端改不了
- 9 个公开数据源并行查询后投票：`pconline / vore / useragentinfo / ip-api / ipwho / ipwhois.app / ipapi.co / ip.sb / ipinfo`
  1. **同一个上游库的多个域名只算一票**（`ipwho.is` 与 `ipwhois.app` 是同一份数据）；
  2. 熟悉的库按准确度加权：`pconline` / `ip.sb` / `ipinfo` 记 3 分，`vore` / `useragentinfo` 2 分，其余 1 分；
  3. 先比「几家库指向同一个省」，再比加权分，最后才比数据源顺序；省内再比城市；
  4. **只要有国内库回过话，就不提前收工** —— 移动/家宽出口被境外库登记成「北京」正是老毛病
- 成功缓存 24 小时、失败缓存 5 分钟；**改了属地算法必须重启服务端**，否则内存里还是旧结论
- 判定结果：本机回环 → `本机`；私网 → `局域网 192.168.x.x`；公网解析成功 → `福建 厦门`；失败 → `属地未知`
- 排查 / 手改：控制台 `geo 1.2.3.4`、`geoset 1.2.3.4 福建 厦门`、`geo save`

## 数据、目录与限额

服务端目录（exe / `chat_server.py` 同目录）：

| 路径 | 内容 |
| --- | --- |
| `server_config.json` | 上面那张表的参数 |
| `social_data.json` | 账号（盐 + 口令散列）、好友、黑名单、群组（成员 / 管理员 / 禁言 / 公告 / 群文件 / 待审批）、离线留言、封禁记录 |
| `avatars/` | 用户上传的头像（256×256 PNG，按昵称 + 版本号命名） |
| `group_files/<群号>/` | 群文件（长期保留，不参与临时缓存淘汰） |
| `history/*.jsonl` | 每个会话的历史消息（每行一条 JSON） |

换服务器时把这几个一起拷走 = 账号、好友、群、历史、头像全部保留。
临时文件缓存在 `%TEMP%\qiaoni_server\`（上限 50 个 / 4GB，正常退出清空）。

| 限额 | 取值 |
| --- | --- |
| 单条消息 | 最长 2000 字 |
| 昵称 / 密码 | 2–16 字符 / 至少 4 位 |
| 群成员上限 | 60 人 |
| 群号 | 6 位数字 |
| 每个会话落盘历史 | 最多 200 条 |
| 新入群补历史 | 最近 30 条 + 一份群资料 |
| 离线留言 | 每人最多 200 条，保留 30 天 |
| 撤回 | 自己的消息 2 分钟内；群主 / 管理员撤普通成员不限时间 |
| 文件 | 分块 1000 字节；单文件上限 4 GB（等于不限） |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 客户端一直连不上 | 安全组 / 防火墙放行 **UDP** 端口；确认没填错 IP / 端口；看服务端窗口有没有启动成功 |
| 控制台报端口被占用 | 已经有一个服务端在跑（或被别的程序占了），换端口或先关掉旧的 |
| 属地显示「属地未知」 | 联网查询失败：`geo self` 看原因；或配 `geo_api`；或直接 `geoset` 手动指定 |
| 想清空所有数据重来 | 关掉服务端，删 `social_data.json`、`history/`、`avatars/`，再启动 |
| 服务端重启后老客户端卡住 | 客户端心跳（3 秒）会收到「会话失效」标记并自动重连，最多等几秒 |
| 想换端口又要保留数据 | 只改 `server_config.json` 的 `port`，其他文件别动 |
